# Runtime audio fixtures

`mandarin-classroom.wav` and `english-classroom.wav` are deterministic PCM WAV files generated by Windows' installed Microsoft speech voices. They contain synthetic classroom speech only and no user data.

Regenerate them on Windows with:

```powershell
pwsh -NoProfile -File tests/runtime/generate-fixtures.ps1
```

Acceptance smoke checks require each file to produce at least one non-empty timestamped transcript segment. The Mandarin transcript should contain recognizable classroom concepts or assignment language; the English transcript should contain `working memory`, `assignment`, or equivalent recognizable phrases.
