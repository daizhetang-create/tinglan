# 听澜 · Tinglan 0.5

> 把课堂录音变成可回听、可引用、可复习的学习资料。

听澜是本地优先的课堂录音、实时中英转写、翻译和证据化学习资料库。它使用浏览器处理录音和实时文字，本机 Small 模型做长音频精校，再通过用户自己的 ChatGPT/Codex 登录生成带来源的课堂纪要、作业和考试信息。

## 启动成品

在正式目录 `C:\Users\HP\Documents\11\lectureflow-local` 双击 **启动听澜.cmd**。同一启动器负责网站和本机 AI 后端，地址为：

[打开听澜](http://127.0.0.1:4318/)

需要 Node.js 22.12+、已安装的 Codex CLI，以及可用的 ChatGPT Codex 登录。预构建交付包无需 Git、PowerShell 7 或项目依赖即可启动；源码更新或构建损坏时才用 npm 安装并构建。若提示旧服务或端口冲突，先结束正在录制的任务，再处理已确认属于听澜的旧服务，不要盲目结束其他进程。

长音频精校使用本机 Python 3.12 + faster-whisper Small（CPU int8）。这台电脑已配置；其他电脑运行 **配置本机转写.cmd**，首次需要网络下载依赖和约 500 MB 模型。它使用独立环境，不要求额外 API 余额。若设置过 `TINGLAN_PYTHON`，必须指向可用引擎，否则配置会明确报错。

开发命令（不是成品启动方式）：

```powershell
npm ci
npm run check
npm run build
npm start
```

开发时另开 `node server/index.mjs` 和 `npm run dev`。不同端口的浏览器存储互相隔离；请始终在 4318 查看自己的正式资料。

## 使用流程

1. 先查看顶部连接状态；正常显示 Codex 已连接。登录过期时在设置中通过 ChatGPT 重新登录，**不需要粘贴 API Key、Cookie 或访问令牌**。
2. 选择英文→中文或中文课堂，点击新建录音。授予麦克风权限；电脑声音需在浏览器选择器中明确勾选共享音频。
3. 录制过程中本地 Whisper Tiny 分块产生文字，英文随段翻译为中文。实时要点由 Codex 节流更新，并非每个字即时调用。
4. 停止后先保存原始音频，再自动精确转写、翻译、生成完整分类纪要。优先使用本机 Small，每次仅解码约 64 秒 PCM；未配置时只有已知不超过 10 分钟且 64 MB 的短音频才回退浏览器 Base/Tiny。长音频保留原件并提示配置，不尝试整堂课解码占满内存。
5. 旧录音失败时用“重新转写并整理”；已有文字时可单独重试纪要。取消、断网或 AI 配额不足不会删除已保存的录音和文字。
6. 创建课程后批量导入音频，或者在录音页“追加本堂课音频”。纪要范围可选择单段、本堂课多段、整门课程；来源按钮可跳到对应音频时间。
7. Class Brief 按核心概念、老师强调、作业和截止日期、考试/阅读、待跟进事务分类。单独问答显示在纪要上方，不覆盖完整纪要。
8. 打开“学习资料库”，可一次选择图片、文字及多段音频。原件先保存，图片交给 Codex 实际识别；按课程、作业/课件/阅读/通知分类。分类课程仅限已创建且原文出现的课程，可手工修正。
9. 在“问我的资料”查作业内容、字数单位、提交方式、DDL 或考试安排。每条结论附原文来源；录音来源可以回听。相对日期保留原话，不编造日历日期。超出单次容量时明确显示检索覆盖率。
10. “作业与考试”汇集图片和录音笔记中的要求；选中资料可并排查看原件和引用。现支持 PNG/JPG/WebP（每张 8 MB）、TXT/MD（600 KB）及浏览器能解码的音频，不支持 PDF/Office。
11. 本机已有个人学习资料库时，新资料理解完成后自动归档原件和带证据笔记，按 SHA-256 去重。不会扫描私人目录或覆盖人工笔记；失败显示重试，识别疑点保留待核对状态。图片可以点击“同步到本机学习资料库”重试；音频可以重新整理重试。

首次运行会下载 Hugging Face 的本地转写/翻译模型，请保持网络畅通并等待进度。已缓存模型时，两小时测试的首段文字约 13.3 秒；实际时间取决于机器、网络和音频，不能保证零延迟。停止后的精校比实时 Tiny 慢。原生浏览器翻译初始化超时会尝试本地模型，失败不会无限循环重载。

## ChatGPT 订阅路线与隐私

- 浏览器负责录音、存储、Whisper 实时转写和本地翻译；本机 Python 负责长音频分窗精校。
- 本机后端仅监听 127.0.0.1；通过官方 Codex app-server 和已有 ChatGPT 登录调用 **gpt-5.6-luna / low**。
- Codex 请求发送所选课堂**文字/图片**并消耗可用 Codex 配额；ChatGPT 订阅不是 OpenAI API 钱包。本版本不调用付费 OpenAI Audio API，也不要求额外 API 密钥。
- 这是真实的 Codex 会话桥接，不是对桌面任务栏做自动点击，也不承诺临时 AI 会话在任务栏中一一显示。
- 原始音频保存在浏览器，配置好的本机学习库另存归档副本；音频文件不会作为 OpenAI Audio API 上传。图像识别会将所选图片发送给 Codex。录音可手动选择本地规则模式，但图像识别与学习库语义问答需要 Codex，不会伪装为本地规则能力。
- 不要把密钥、令牌、私人音频提交到 Git 或共享协作文档。

## 备份与实际边界

设置页提供含原始音频、图文原件、课程、转写和笔记的完整备份/恢复。数据库 v4 保留旧录音并增加录音分段日志；备份格式 v2 仍读取旧 v1。恢复先验证全部内容、原件校验和及引用，重复记录重新分配 ID，不覆盖现有资料。精校草稿不会覆盖旧的完整字幕，失败可查看草稿、重试。备份文件**未加密**，请妥善保管。学习库临时问答不随备份保存；已生成的资料笔记、来源和原件会保存。

- 清除站点数据会删除本地资料，操作前先备份。
- 保持电脑开机、页面打开；没有后台断点任务服务。录音每秒写入分段日志，重启可恢复已经提交且可解码的连续前缀；最后未提交或容器未完整封口的尾音仍可能丢失。不要把恢复机制当成不需要正常停止保存。
- 两小时实时合成语音压力测试通过（冻结 0.4 实时引擎），0.5 本机引擎通过两小时稀疏语音文件测试；不等于两小时密集课堂准确率、睡眠唤醒、嘈杂教室/真实麦克风或全部设备认证。
- 没有自动说话人分离；识别与翻译仍会出错。重要日期、数量、作业要求请用来源时间戳回听确认。
- 录制前取得必要同意，并遵守课堂规定。

## 两个聊天如何共同开发

把 `C:\Users\HP\Documents\vibe Coding\Tinglan\SKILL.md` 发给另一个聊天即可作为协作入口。它会先读取本仓库的完整协调 Skill，再创建独立任务 worktree。不要让两个聊天直接编辑同一 checkout，也不要复制整个文件夹互相覆盖。

```powershell
npm run coord -- doctor
npm run coord -- status
```

任务认领、检查、发布和主线合并会将共享状态自动写入上述文件夹的 `LIVE_STATUS.json`。唯一验收版本是 main；新聊天应先同步接受的版本，按不同文件范围工作，完成后进入集成队列。规则与测试见 [交接说明](docs/coordination/NEW_CHAT_HANDOFF.md)。
