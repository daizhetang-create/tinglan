# 听澜（Lecture Flow）

一款为国际生课堂场景制作的本地优先录音、双模式转写、中文对照翻译与课堂纪要应用。

界面借鉴了成熟会议笔记工具的核心工作流，但品牌、视觉、代码与图形均为原创实现，并未复制 Notta 的商标、私有代码或素材。

> **当前状态（2026-09-03）：产品恢复中。** 录音、播放、本地存储、课程分组和导出有真实实现；当前浏览器 ONNX q8 运行时无法创建 Whisper 会话，因此转写、翻译和依赖字幕的 Notes 主链路尚不可用。当前 Notes 是规则引擎，不是 GPT/Codex。请以 [产品恢复状态](docs/coordination/PROJECT_STATUS.md) 和真实验收结果为准，不要把下面的原型功能清单理解为已经通过生产验收。

## 原型已包含

- 麦克风录音，以及 Edge/Chrome 的电脑/共享标签页声音录制
- “英文转中文”与“纯中文课堂”两种录音模式
- 浏览器实时字幕；英文模式在完整句结束后自动生成简体中文
- 导入一个或多个已有音频，使用本地 Whisper 模型进行课后精确转写
- 英文音频自动选用体积更小的 Whisper `.en` 模型，中文及其他语言自动切换多语言模型
- 英文原文与中文译文并排在同一时间轴上
- 时间戳笔记、重点收藏、点击时间回听、逐段人工修改
- 自动提取 Key Messages，并按概念、强调、作业、考试、提问和课程安排分类
- 生成包含核心概念、关键结论、作业、考试阅读与待跟进事项的 Class Brief
- 使用 Course 对同一门课的多次录音进行分组，旧资料会自动归入“未分组”
- IndexedDB 本地保存课程、录音、字幕、纪要、笔记与设置
- 搜索资料库，导出包含 Key Messages 与 Class Brief 的 Markdown、TXT、JSON，以及双语 SRT 和原始音频
- PWA 安装、离线应用外壳、桌面/平板/手机响应式界面

## 启动

电脑已安装 Node.js 时，双击 `启动听澜.cmd`；或在本目录运行：

```powershell
npm install
npm run dev
```

然后打开 <http://127.0.0.1:4317/>。生产版检查可运行：

```powershell
npm run check
npm run build
npm run preview
```

生产预览地址为 <http://127.0.0.1:4318/>。

## 第一次使用

1. 推荐最新版 Microsoft Edge 或 Google Chrome。
2. 点击“新建录音”，选择麦克风或电脑声音。
3. 按课堂语言选择“英文转中文”或“纯中文”；麦克风模式可使用浏览器实时字幕，电脑声音模式停止后点击“本地精确转写”。
4. 首次使用本地翻译或 Whisper 会从 Hugging Face 下载模型，后续由浏览器缓存复用。
5. 批量导入的文件会逐条分析，关闭当前页面会中止尚未完成的本地分析任务。
6. 分享屏幕/标签页声音时，必须在浏览器选择器中勾选“共享音频”。这是浏览器的安全要求，应用无法绕过。

## AI 与 API 密钥

- 默认工作流无需 GPT API：Whisper 转写、本地翻译、Key Messages 和 Class Brief 均由浏览器模型或本地规则完成。
- 当前前端不会读取、保存或上传 `OPENAI_API_KEY`，也不需要创建该环境变量。
- 如果未来增加 OpenAI 增强能力，只允许由本机代理或受控后端进程读取 `OPENAI_API_KEY`，前端只能调用该代理提供的受限接口。
- 不得把密钥写进源码、`VITE_*` 环境变量、浏览器 localStorage、IndexedDB 或导出文件。`VITE_*` 会被打包进前端，不能用于保存任何秘密。

## 隐私边界

- 听澜当前版本没有后端，课程、录音与课堂资料保存在当前浏览器的 IndexedDB 中。
- 浏览器实时字幕是否调用浏览器厂商的网络服务，取决于 Edge/Chrome 的具体实现与设置。
- 需要严格离线时，可先录音，再运行本地 Whisper 精确转写；本地模型首次下载仍需要联网。
- 清理浏览器站点数据会一并删除听澜资料，请定期导出重要记录。
- 录制课堂、会议或他人发言前，请遵守学校规定并取得必要同意。

## 当前边界

- 浏览器原生实时字幕只能直接听麦克风，不能把自定义系统音频流注入其识别器；系统声音采用“完整录制 → 本地精确转写”。
- 首版不做自动说话人分离，默认显示“讲师”，可逐段编辑。纯浏览器同时运行说话人分离、Whisper、翻译与纪要会明显增加内存占用。
- Key Messages 与 Class Brief 是学习辅助结果；音频不清晰或专业术语密集时，应回听原文并人工校对。
- 本地模型适合个人学习和课堂草稿，不应作为法律、医疗或无障碍字幕的唯一依据。
