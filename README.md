# 听澜 · Tinglan 0.3

本地课堂录音、实时中英转写、英文中文对照，以及使用 ChatGPT 订阅 Codex 配额的课堂助手。采用熟悉的双栏会议笔记工作流，不使用 Notta 私有代码或账号。

**当前状态（2026-09-08）：核心链路已恢复，并通过真实模型和浏览器流程测试。** 完整证据及未验证范围见 [验收记录](docs/coordination/RELEASE_ACCEPTANCE.md)，当前协同状态见 [PROJECT_STATUS](docs/coordination/PROJECT_STATUS.md)。不把“构建成功”视为所有课堂场景已验证。

## 使用流程

1. 先查看顶部连接状态；正常显示 Codex 已连接。登录过期时在设置中通过 ChatGPT 重新登录，**不需要粘贴 API Key、Cookie 或访问令牌**。
2. 选择英文→中文或中文课堂，点击新建录音。授予麦克风权限；电脑声音需在浏览器选择器中明确勾选共享音频。
3. 录制过程中本地 Whisper Tiny 分块产生文字，英文随段翻译为中文。实时要点由 Codex 节流更新，并非每个字即时调用。
4. 停止后先保存原始音频，再自动精确转写、翻译、生成完整分类纪要。新设置默认使用 Base 精确模型；可在设置切换速度/精度。
5. 旧录音失败时用“重新转写并整理”；已有文字时可单独重试纪要。取消、断网或 AI 配额不足不会删除已保存的录音和文字。
6. 创建课程后批量导入音频，或者在录音页“追加本堂课音频”。纪要范围可选择单段、本堂课多段、整门课程；来源按钮可跳到对应音频时间。
7. Class Brief 按核心概念、老师强调、作业和截止日期、考试/阅读、待跟进事务分类。单独问答显示在纪要上方，不覆盖完整纪要。

首次运行会下载 Hugging Face 的本地转写/翻译模型，请保持网络畅通并等待进度。已缓存模型时，测试样本的首次实时文字约 12 秒；实际时间取决于机器、网络和音频，不能保证零延迟。停止后的 Base 精确整理比实时 Tiny 慢。

## ChatGPT 订阅路线与隐私

- 浏览器负责录音、存储、Whisper 转写和本地翻译。
- 本机后端仅监听 127.0.0.1；通过官方 Codex app-server 和已有 ChatGPT 登录调用 **gpt-5.6-luna / low**。
- Codex 请求发送课堂**文字**并消耗可用 Codex 配额；ChatGPT 订阅不是 OpenAI API 钱包。本版本不调用付费 OpenAI Audio API，也不要求额外 API 密钥。
- 这是真实的 Codex 会话桥接，不是对桌面任务栏做自动点击，也不承诺临时 AI 会话在任务栏中一一显示。
- 原始音频保留在浏览器本机；使用 Codex 时转写文字会发送给 OpenAI。需要纯本地时可以手动选择本地规则模式，但它不具备大模型语义问答能力。
- 不要把密钥、令牌、私人音频提交到 Git 或共享协作文档。

## 备份与实际边界

设置页提供含原始音频、课程、转写和笔记的完整备份/恢复。恢复先验证全部内容，重复记录重新分配 ID，不覆盖现有资料。备份文件**未加密**，请妥善保管。

- 清除站点数据会删除本地资料，操作前先备份。
- 保持电脑开机、页面打开；没有后台断点任务服务。正在录制但尚未停止保存的音频不保证在浏览器崩溃后恢复。
- 尚未完成 60–120 分钟长课压力测试、嘈杂教室/真实麦克风验收和全部设备兼容测试。
- 没有自动说话人分离；识别与翻译仍会出错。重要日期、数量、作业要求请用来源时间戳回听确认。
- 录制前取得必要同意，并遵守课堂规定。

## 两个聊天如何共同开发

把 `C:\Users\HP\Documents\vibe Coding\Tinglan\SKILL.md` 发给另一个聊天即可作为协作入口。它会先读取本仓库的完整协调 Skill，再创建独立任务 worktree。不要让两个聊天直接编辑同一 checkout，也不要复制整个文件夹互相覆盖。

```powershell
npm run coord -- doctor
npm run coord -- status
```

任务认领、检查、发布和主线合并会将共享状态自动写入上述文件夹的 `LIVE_STATUS.json`。唯一验收版本是 main；新聊天应先同步接受的版本，按不同文件范围工作，完成后进入集成队列。规则与测试见 [交接说明](docs/coordination/NEW_CHAT_HANDOFF.md)。

开源组件和模型归属见 [NOTICE.md](NOTICE.md)。
